# Glossary

| Term | Meaning |
| --- | --- |
| Assumption | A temporary condition accepted for analysis and recorded explicitly. |
| Claim | A proposition that can be supported, challenged, or left unresolved. |
| Context | Conditions that affect interpretation of an object, claim, or action. |
| Counterfactual | An analysis of what might happen if a relevant condition changed. |
| Evidence | Information that bears on a claim, with provenance and limitations. |
| Hypothesis | A candidate explanation or interpretation. |
| Liability surface | Points where decisions, omissions, or dependencies may create exposure. |
| Mnemosynth | The project’s concept of memory combined with synthesis and recursive interpretation. |
| PHCA | The project’s context-, hierarchy-, and phase-oriented analytical model; its exact expansion remains to be formally specified. |
| Provenance | The origin, history, and transformation record of information. |
| Recursive inference | Iterative refinement of hypotheses using new evidence and constraints. |
| Reasoning trace | An inspectable record of inputs, transformations, intermediate states, and outputs. |
| Symbol | An explicit representation of an entity, property, action, claim, relation, or transformation. |
| Uncertainty | Incompleteness, ambiguity, disagreement, measurement limits, or model limitations. |
